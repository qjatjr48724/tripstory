# tripstory 에이전트 핸드오프

Windows ↔ Mac 등 **다른 환경/다른 채팅**에서 개발을 이을 때 쓰는 기준 문서입니다.  
새 에이전트에게는 이 파일 전체를 읽게 하거나, 아래 「에이전트에게 붙여넣을 요약」을 전달하세요.

---

## 유지 규칙 (중요)

### 언제 업데이트하나
작업 세션이 끝나기 **직전**, 또는 **커밋·푸시 직후**에 이 문서를 갱신한다.

- Mac에서 작업 끝 → 여기 업데이트 후 커밋·푸시 → Windows에서 pull 후 이어서
- Windows에서 작업 끝 → 여기 업데이트 후 커밋·푸시 → Mac에서 pull 후 이어서

### 무엇을 고치나
1. **완료된 단계** — 이번 세션에서 끝난 것을 ✅로 옮긴다.
2. **다음에 할 일** — 바로 이어서 할 단계·세부 작업을 구체적으로 적는다.
3. **최근 변경 / 주의** — 환경·스키마·임시 결정·알려진 버그를 남긴다.
4. **테스트 현황** — 실기기/계정으로 확인한 범위를 적는다.
5. 필요하면 맨 아래 **「에이전트에게 붙여넣을 요약」**도 같은 내용으로 맞춘다.

### 커밋
핸드오프 수정은 가능하면 **기능 커밋과 함께** 또는 바로 이어서 푸시한다.  
다른 PC에서 문서만 옛것이면 에이전트가 단계를 다시 밟거나 잘못된 전제로 작업한다.

### 에이전트에게 시킬 말 (세션 종료 시)
> 이번 작업 반영해서 `docs/에이전트_핸드오프.md`의 완료 단계·다음 할 일·주의·테스트 현황을 업데이트하고, 커밋·푸시에 포함해줘.

### 로컬 세팅
```bash
git clone https://github.com/qjatjr48724/tripstory.git
cd tripstory
git pull origin master
flutter pub get
cp .env.example .env   # Mac/Linux
# Windows: copy .env.example .env
```
`.env`에 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 입력. **`.env`는 커밋하지 않는다.**

선택(장소 검색):
- 해외: `GOOGLE_PLACES_API_KEY` (검색 시에만 호출)
- 국내: `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` (NAVER API HUB · 지역)

- `SUPABASE_URL`은 `https://xxxx.supabase.co` 형태 (`/rest/v1/` 붙이지 말 것)
- DB 마이그레이션 SQL은 `supabase/migrations/` — **대시보드에 적용했는지 확인**

## 최근 변경 / 구현 시 주의

- 국내 장소 검색: NAVER API HUB **지역** (`NAVER_CLIENT_ID`/`SECRET`). Maps API는 Place ID를 안 줌
- 지도에서 보기(국내): `nmap://place?lat&lng&name` 앱 딥링크 우선 → 웹 폴백
- `.env` 변경 후 **flutter run 재실행** 필요
- **10단계 SQL 필수:**
  1. `20261007000000_travel_links_and_storage.sql` (`travel_links` + Storage `travel-media`)
  2. `20261007010000_reservation_linked_expense.sql` (`reservations.linked_expense_id`)
- 예약에 비용 입력 시 비용 장부에 자동 등록(결제자=예약자, 활성 구성원 1/N). 정산 완료된 연결 비용은 수정하지 않음
- 이미지: 갤러리 선택, 장당 최대 5MB, 서명 URL(1시간)로 표시
- GoRouter 라우트 추가 시 **핫 리스타트/재실행**
- 정산: 본인 기준 받을/낼 돈·구성원별 묶음
